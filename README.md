# 🔐 Página de Login

Tela de login com registro de usuários, recuperação de senha e validações, tudo em JavaScript puro sem back-end.

## Funcionalidades

- Login com validação de e-mail e senha
- Opção "Lembrar e-mail" via localStorage
- Cadastro de novos usuários com validação de campos
- Modal de "Esqueci minha senha" com feedback visual
- Animação de shake no formulário em caso de erro
- Toast de notificação para ações bem-sucedidas
- Feedback de carregamento no botão de login
